# 每日学习计划 · Daily Study Planner

一个轻量的本地学习计划管理工具：把一天的 24 小时切成时间段，逐条安排学习任务，到点自动提醒并记录完成情况。

后端是单文件 Flask 应用，数据存 SQLite，前端是原生 HTML/CSS/JS，不依赖任何构建工具。双击启动就能用，适合学生和自学者做每日时间管理。

## 功能特性

### 账号与登录
- 登录页填写姓名、年龄、性别即可
- 按姓名自动注册/登录，无需密码，换设备也能找回自己的数据

### 24 小时计划表
- 自定义开始时间、结束时间、计划内容
- 时间轴可视化 + 列表两种视图，直观看到一天的空档和任务
- 支持添加、编辑、删除计划

### 计时与提醒
- 每条计划带「开始」按钮，点击后进入倒计时
- 到达结束时间自动播放声音提示，并标记「已完成」
- 记录实际开始时间和实际用时，支持提前开始
- 到点未开始的计划自动标记「未完成」

### 自动生成计划
- 打开某一天时，系统自动补全当天计划
- 生成优先级：长期目标 → 过去 28 天同星期几的高频任务和历史时段
- 与已有计划时间冲突时自动跳过
- 历史习惯每个日期只生成一次，删除或修改后不会被自动恢复
- 需要重建时点「重新生成」，手动改过的计划会被保留

### 长期目标
- 目标包含：名称、每日任务、开始/结束日期、每日时段、执行星期（可多选）
- 在目标范围内，每个执行日自动生成一条每日计划，并显示「目标」徽章
- 修改目标会重建「今天起、未开始」的目标计划，已完成记录保留
- 删除目标只清理未来未开始的计划，历史记录不动
- 目标卡片显示进行状态、已安排天数、已完成天数

### 过期任务处理
- 计划时间已过且未完成，不能再开始，提示「计划时间已过，你并没有完成该计划」
- 两种处理方式：
  - **结束任务**：标记未完成并保留记录
  - **延顺任务**：选择新日期和时段，重新变为待开始

### 完成度统计
- 每日统计：总计划 / 已完成 / 进行中 / 未完成 / 完成率

## 技术栈

| 层 | 选型 |
| --- | --- |
| 后端 | Python 3 + Flask（单文件 `app.py`，约 950 行） |
| 数据库 | SQLite（Python 内置 `sqlite3`，无需额外服务） |
| 前端 | 原生 HTML + CSS + JavaScript（无框架、无打包） |
| 运行方式 | 本地 Flask 服务，默认 `http://127.0.0.1:5001` |

依赖极简，`requirements.txt` 只需要 `flask>=2.0`。

## 快速开始

要求：Python 3.9 及以上。

```bash
git clone https://github.com/taociwan/daily-study-planner.git
cd daily-study-planner

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

浏览器打开：

```
http://127.0.0.1:5001
```

> 用 5001 而不是 5000，是为了避开 macOS「AirPlay 接收器」占用的 5000 端口。

### macOS 一键启动

不想敲命令，直接双击 `启动学习计划.command`：

- 自动用 `venv` 里的 Python 在后台启动服务
- 已经在跑就直接打开浏览器
- 双击 `停止学习计划.command` 结束进程

## 使用流程

1. 登录页填写姓名、年龄、性别，进入计划页
2. 先建「长期目标」（可选），系统会按执行日自动铺计划
3. 手动补充或调整当天的时段安排
4. 到点点击「开始」，倒计时结束自动提醒并标记完成
5. 忘掉的计划用「结束任务」或「延顺任务」收尾
6. 看当天完成率，复盘时间利用情况

## 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/login` | 按姓名登录/注册 |
| GET | `/api/plans` | 查询某天计划 |
| POST | `/api/plans` | 新增计划 |
| PUT | `/api/plans/<id>` | 编辑计划 |
| DELETE | `/api/plans/<id>` | 删除计划 |
| POST | `/api/plans/generate` | 按历史习惯重新生成当天计划 |
| POST | `/api/plans/<id>/start` | 开始计划，记录实际开始时间 |
| POST | `/api/plans/<id>/complete` | 标记完成 |
| POST | `/api/plans/<id>/close` | 结束未完成的任务 |
| POST | `/api/plans/<id>/postpone` | 延顺到新日期和时段 |
| GET/POST | `/api/goals` | 查询 / 新建长期目标 |
| PUT/DELETE | `/api/goals/<id>` | 修改 / 删除长期目标 |
| GET | `/api/summary` | 当天完成度统计 |

## 数据说明

- 所有数据存本地 `study_planner.db`，不上传、不联网
- 首次运行自动建表，无需手动初始化
- 仓库不包含任何个人计划数据，克隆后是干净的空库
